Five steps, no firmware swap, on the stock OS or on CrossMix. You need the handheld, its SD card and Wi-Fi. Ten minutes from now it is a media and gaming console.

Install on the SD card

  1. Download JukaHub-Trimui.zip from the latest release.
  2. Turn the handheld off and put its SD card in your computer.
  3. Extract the zip. Inside is one folder, JukaHub-Trimui.
  4. Rename that folder to JukaHub and copy it into the card's Apps folder, so that launch.sh ends up at Apps/JukaHub/launch.sh.
  5. Put the card back, power on, and open Apps, then JukaHub.

When you are done, the folder looks like this. That is the whole installation:

SDCARD/Apps/JukaHub/
├── JukaHub            the application
├── launch.sh
├── config.json        the Apps-menu entry
├── jukaconfig.json    the interface
├── JukaPlayer.png     the icon in the Apps menu
├── Inter-Regular.ttf
├── background.jpg
├── SECURITY.md        read by Tools → Security & trust
└── release-info.json  which build this is

There is nothing else to set up. The firmware already ships SDL2, so there are no extra libraries, and no Python or build tools are needed on the device.

If JukaHub does not appear in Apps, reboot: the stock launcher only scans Apps at startup. Also check that the folder is exactly Apps/JukaHub and that launch.sh is directly inside it, not in a JukaHub-Trimui folder one level down.

First run

The first start fetches two helpers, yt-dlp and ffmpeg, which needs Wi-Fi and takes a minute or two, once. Later starts are instant.

Home is a grid of tiles: Continue, Media, Files, Packages, Apps, Favorites, Browser, Chat, Tools, Emulator and Settings, with Exit in the footer. The PS4 and PS5 pills and the phone-pairing QR sit under the top bar on the right; the weather, the clock and the notification bell are in the bar itself.

Turn Wi-Fi on in Quick Settings, then join a network from Quick Settings → Wi-Fi Networks before using YouTube or the weather. Your settings are stored in Apps/JukaHub/jukauser.json and survive updates.

Copy files from a PC

  1. Connect the handheld to the same Wi-Fi as your PC.
  2. Open Tools and note the IP address. Press A to copy it.
  3. Start the FTP server in Tools → Network tools. The panel shows the address, such as ftp://192.168.1.42:2121, the user name juka and a password made up for this start.
  4. On your PC, paste that address into Explorer or Finder (or any FTP client), sign in, and drop files into Roms, BIOS, Saves or your media folders.

The rest of the card, including the apps, emulator scripts and system files, is not shared. FTP is not encrypted, so on a network you do not trust use Tools → SSH / SFTP instead: it speaks SFTP only, with a random password for every start, and works with WinSCP, FileZilla, Cyberduck, Finder or the sftp command. Both servers switch themselves off after 15 idle minutes or when the handheld changes network.

Use your phone as a keyboard

Typing a search on a D-pad is slow. Tools → Phone companion shows a QR code; scan it with your phone camera (phone and handheld on the same Wi-Fi) and the phone opens a small page with:

  • Type: a text box whose contents appear in whichever field has focus.
  • Remote: D-pad, A, B, X, Y, Start, Back and the shoulder buttons.
  • Send a link: paste a YouTube, video or stream link and it starts playing on the handheld.
  • Send a file: uploads land in the PhoneDrop folder, ready for the file browser or the player.

The QR carries a fresh six-digit PIN, so nothing has to be typed on the device. Y issues a new PIN on the spot, which also invalidates every link already shared.

Updating

JukaHub updates itself. When a newer release exists, a download icon appears in the Home header. Select it and press A: JukaHub downloads the archive for your platform, checks it against the SHA-256 digest GitHub publishes and, when the release ships a signed release.json, verifies its Ed25519 signature. Then it replaces the app files and restarts.

Your jukauser.json settings, favorites and media are untouched, and an interrupted update is rolled back at the next launch. After the restart, What's new opens once with that release's notes. To turn automatic checks off, set JUKAHUB_NO_AUTOUPDATE=1, or update by hand by extracting a new release over Apps/JukaHub.

Something wrong?

The logs are on the SD card, so you can read them on a PC without SSH.

ProblemWhat to do
Not in the Apps menuReboot. Check the folder is Apps/JukaHub and contains launch.sh.
Black screen, or it closes at onceSend Apps/JukaHub/errors.txt (the launcher's log) and the newest crash-*.txt next to it. On Windows they are in %LOCALAPPDATA%\JukaHub\logs.
A plugin, a setting or an update broke startupHold L + R + Start while JukaHub starts for safe mode and a recovery card: the previous version, your last good settings, or a reset. Three failed starts in a row open it by themselves.
The screen blinks between the stock menu and JukaHub after an updateThe launcher on the card is older than the app. Update once more, or copy launch.sh from the release archive over Apps/JukaHub/launch.sh, then reboot.
YouTube search failsCheck Wi-Fi, then open Logs from the Start menu.
Video stuttersSettings → playback resolution: try 480 or 360.
Text shows as boxesInter-Regular.ttf is missing from Apps/JukaHub.

Still stuck? Tools → Community & support → Report a bug opens a GitHub issue with redacted diagnostics already filled in, or ask on Discord.

Uninstall

Delete the Apps/JukaHub folder. JukaHub keeps its settings and data inside it, so a few things are worth doing first:

  • Keep your snapshots and downloads. Save Manager snapshots are in Apps/JukaHub/data/save-manager, and saved music and videos in data/downloads. Copy them out if you want them.
  • Turn off Start at login if you switched it on: it adds System/starts/jukahub-autostart.sh outside the app folder.
  • Know what stays with your games. Save-state resume turns on RetroArch's auto-save and auto-load (the original setting is kept as retroarch.cfg.jukahub-backup), and cue sheets or playlists made by Disc helpers stay next to your ROMs. Both keep working without JukaHub.
